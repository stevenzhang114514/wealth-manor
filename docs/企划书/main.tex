% ---------------- 3.1 平台理念 ----------------
\subsection{平台理念}

\subsubsection{使命与愿景}
财富庄园的使命是\textbf{"让理财像玩游戏一样简单，让每个人都能看清自己的全部财富版图"}。
平台相信：理财不应是少数人的专业游戏，而应是每个人日常生活的组成部分。
通过把抽象的金融概念翻译成用户熟悉的"种植—生长—收获"语言，把分散的资产
汇聚成一棵看得见的"财富树"，理财从一件"该做但不想做"的事，变成一件
"想主动去做"的事。

\subsubsection{三大设计原则}
\begin{enumerate}
  \item \textbf{行为即游戏，游戏即成长}：每一种真实理财行为（购买、定投、查看、
        学习）都对应庄园中的确定性反馈（种子、生长加速、金币、经验），
        让好习惯即时获得正反馈；
  \item \textbf{规则真实，情境模拟}：模拟器中的产品七维参数、风评门槛与市场联动逻辑全部取自真实金融世界，模拟的是人生剧本而非金融规则；财富庄园与资产看板映射用户的真实资产，游戏中学到的每一条经验都能直接用于现实理财；
  \item \textbf{普惠与合规并重}：面向零基础用户降低门槛，同时严守金融合规红线——
        游戏积分不可兑换现金、理财产品购买走正规流程、资产数据仅展示不存储明细。
\end{enumerate}

% ---------------- 3.3 功能介绍 ----------------
\subsection{功能介绍}
平台由\textbf{夺金冒险局}（核心玩法）、\textbf{智能全资产看板}与\textbf{财富庄园成长陪伴层}三大模块构成，形成"好玩优先—决策支撑—长期陪伴"的产品结构。

\subsubsection{1. 模块一：夺金冒险局（核心玩法）——横屏地牢探险}

\textbf{（1）横屏地牢地图。}夺金冒险采用\textbf{横屏地牢探险}形态：地牢为 9$\times$6 共 54 个房间的随机连通地图，每个房间即一个\textbf{板块}（经济作物🌾/粮油🥜/金属⚙️/油气🛢️），房间\textbf{随机生成并相互连通}构成可探索地图。玩家在房间间移动，房间可能没有箱子，也可能有\textbf{低级/中级/高级}箱子；进入房间前地图为迷雾，进入后揭开房间的板块、箱子与危险。房间深处还可能盘踞\textbf{怪物}——它们是导致玩家损失钱的金融风险事件的化身。

\textbf{（2）限时撤离。}每一局都是真实的\textbf{倒计时探险}：简单/普通/困难/噩梦模式的限时分别为 90/75/60/45 秒。玩家须在时间内移动开箱、积攒金币并\textbf{返回入口房间}，达标（初始资金的1.5$\sim$5倍）即可撤离带出收益；时间耗尽未撤离或金币清零即失败；每移动一步还会额外扣除 0.5 秒倒计时——漫无目的地折返会付出真实的时间代价，路径规划本身成为策略的一部分。紧迫的时间压力让"继续深入还是见好就收"成为每一秒都在做的决策。

\textbf{（5）怪物 = 金融风险事件化身（三选博弈）。}地牢深处盘踞的怪物，是把"导致玩家损失钱的金融事件"拟人化的设计——股灾妖（黑天鹅）、债魔（信用暴雷）、流动性魔（冻结）、通胀巨兽（购买力侵蚀）、狂热幽灵（追涨杀跌）、雷之冲击（突发事件）。遭遇后玩家面临\textbf{三选博弈}：⚔️\textbf{迎战}（随机损失，可能侥幸躲过）/ 🛡️\textbf{防御}（损失固定减半但消耗更多时间）/ 🏃\textbf{逃离}（无损但白耗行动）——把风险管理本身做成每一局都会面对的决策，损失概率与幅度随难度加深。

\textbf{（6）双副收益、撤离排位与消费闭环。}开箱附带双副收益：金币小奖（按容器概率+5$\sim$50）与品质升级（概率升一档）；收益按\textbf{100金币=1元}换算为现实收入展示，成功撤离获得排位分冲击\textbf{青铜至王者}段位；收益进入庄园用于装饰家具消费，好友偷菜与段位榜构成社交闭环。\textbf{3分钟留存}：登录即自动开启新手局（90秒地牢，前3个房间无怪），10秒内完成第一次移动与开箱。

\textbf{（4）AI金融翻译器。}一个只解释名词的翻译器：词条库覆盖ETF、复利、存款保险、净值、年化、波动率、流动性、印花税、风评等级、黑天鹅等常用术语，以"术语$\rightarrow$白话"的卡片形式呈现，回答恒定附注"本翻译器仅解释金融概念，不构成任何投资建议"——把金融教育做在游戏外沿，不触碰投顾合规红线。

\subsubsection{3. 模块三：财富庄园成长陪伴层与生涯模式}
财富庄园作为长期陪伴层，将冒险收益与学习成果转化为可视化的成长：\textbf{种植系统}（真实理财产品对应种子与植物，收益率映射果实品质，提前赎回枯萎、到期赎回丰收）、\textbf{天气系统}（持仓盈亏映射庄园天气）、\textbf{任务系统}（日常/周/月/成就任务引导健康行为）、\textbf{财富树}（树干=总资产、树冠=净资产、树叶茂密度=配置均衡度）与装扮商城、好友互动。此外保留\textbf{生涯模式}（原回合制家庭财富经营模拟器）作为深度教育入口：产品英雄卡七维属性、风评门槛、经济周期与政策事件、目标现金流校验与财富偏差护照，满足希望系统学习的用户。

\subsubsection{4. 核心用户流程}
\textbf{首次使用流程}：手机号登录 $\rightarrow$ 新手局自动开启（进板块开箱）$\rightarrow$ 攒够目标撤离获第一笔收益 $\rightarrow$ 用收益装扮庄园 $\rightarrow$ 尝试更高难度冲击段位 $\rightarrow$（可选）装备解锁评估与生涯模式深度学习。

\textbf{日常使用流程}：夺金冒险一局（3--5分钟）$\rightarrow$ 查看资产看板与体检报告 $\rightarrow$ 完成日常任务 $\rightarrow$ 好友偷菜/浇水/段位榜 $\rightarrow$ 金融翻译器答疑。


\subsection{产品创新}

\subsubsection{六大创新点}
\begin{enumerate}
  \item \textbf{板块地图 $\times$ 容器 $\times$ 五档品质的摸金开箱}：经济作物/粮油/金属/油气四大板块随机游走，股票/债券/基金三种容器（投资方式）可切换，白绿蓝紫金五档品质掉落——更高品质更值钱概率更低，叠加随机暴击、黑天鹅与双副收益，把"收益是分布的"金融世界观装进开箱的多巴胺循环；
  \item \textbf{随机暴击与市场黑天鹅——情绪引擎设计}：暴击翻倍与黑天鹅暴跌交替出现，多巴胺峰值与风险敬畏并存，让用户对"波动"形成肌肉记忆；
  \item \textbf{历史收益分布抽样——收益率不预设}：产品收益由经济周期随机切换与历史收益分布随机抽样叠加生成，不教虚假的固定收益率，而是教"收益是分布的"这一真实金融世界观；
  \item \textbf{四难度排位 + 100:1现实换算}：简单/普通/困难/噩梦与青铜$\sim$王者段位构成竞技纵深；游戏金币按100:1映射现实收入，冒险所得与真实财富同构；
  \item \textbf{收益—庄园—社交的消费闭环}：撤离收益升级庄园装饰家具，好友偷菜、浇水互访与段位榜形成社交攀比与自传播；
  \item \textbf{AI金融翻译器——合规边界的主动设计}：依据《证券投资顾问业务暂行规定》，AI只解释名词、看板只陈述事实，教育价值建立在合规红线之内，形成与同类产品的制度性区隔。
\end{enumerate}

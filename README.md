# 个人理财系统 · Personal Finance System

> 游戏化智能理财与个人财产管理平台 —— 独立产品 · Apple 设计语言
> "让理财像玩游戏一样简单，让每个人都能看清自己的全部财富版图。"

独立形态的个人理财系统：**财富庄园**游戏化引擎驱动理财行为养成，配套全资产看板、任务中心、知识答题、装扮商城、好友排行、AI 助手、目标规划与资产导入。覆盖**全量核心玩法**（登录 → 新手引导 → 庄园经营 → 资产决策 → 个人中心完整闭环）。前后端分离，接口遵循 RESTful 规范，数据层可扩展（Mock ⇄ 真实机构接口）。

**设计**：Apple 浅色设计语言 —— iOS 蓝色系色板、毛玻璃卡片、连续圆角观感、分段控件、SF/PingFang 字体栈。
**响应式**：手机全屏（安全区适配）/ 平板居中宽屏 / 桌面手机框按视口高度自动缩放。

## 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 前端 | Vue 3 + Vite + Pinia + Vue Router + ECharts | 手机框演示形态，`?embed=1` 整屏模式 |
| 后端 | Node.js + Express 5 | `/api/v1` RESTful，统一 `{code,message,data}` 响应 |
| 数据 | Mock Provider（数据驱动 JSON/JS） | 可切换 `DATA_PROVIDER` 对接真实服务 |
| 测试 | node:test（内置，零依赖） | 服务层纯函数单元测试 |

## 快速启动

前置要求：Node.js ≥ 18.18

```bash
# 1. 安装依赖（根目录一键安装前后端）
npm run setup

# 2. 启动后端（终端1，端口 3000）
npm run dev:server

# 3. 启动前端（终端2，端口 5173）
npm run dev:web
```

浏览器打开 **http://localhost:5173** 即可看到手机框演示。

- 底部 Tab 五个主模块：🏡庄园 / 📊资产 / 📋任务 / 🎓答题 / 👤我的；商城/好友/AI助手等从庄园与资产页内入口进入
- 首次访问自动进入登录页（演示模式任意 11 位手机号）；`?skip_login=1` 可跳过守卫（截图/演示用）
- 桌面浏览器两侧为产品说明面板；`http://localhost:5173/manor?embed=1` 为整屏模式（截图/投屏用）
- 后端健康检查：http://localhost:3000/healthz

## 演示路径

1. **登录**：手机号一键登录（演示模式任意 11 位手机号）→ 首次进入自动触发 6 步新手引导 → 创建庄园（名称+风格）
2. **庄园主页**：天气=今日行情（晴/雨/彩虹特效与盈亏联动）→ 点击植物查看关联理财产品 → 成熟后点击「收获」丰收奖励入账（植物归档为木桩）→ 快捷入口宫格
3. **资产看板**：总净资产 → 六大类资产配置饼图 → 30天趋势 → 健康度评分环 → AI建议（预警/一键优化）→ 财富树 → 导入/目标规划入口
4. **任务中心**：日常/周/月/成就任务 → 点击"领取"奖励实时入账 + 金币飞入动画（观察 Tab 右上角金币变化）
5. **知识答题**：每日5题 → 即时判分 → 金币/经验/徽章碎片奖励
6. **装扮商城**：装饰/皮肤/称号 → 购买扣余额 → 装备装饰回到庄园实景渲染
7. **好友与排行**：互访庄园、浇水（每日1次）→ 月度配置合理性 PK 排行榜（本人实时插入）
8. **AI助手·小满**：规则引擎问答（定投/风险/房贷/养老/应急/行情）+ 建议追问
9. **目标规划**：购房/教育/养老/应急测算（4%年化复利）→ 保存到我的目标
10. **资产导入**：四通道（自动同步/扫码/OCR 为流程模拟，手动录入真实入账 → 看板重算）
11. **我的**：头像/风险等级、庄园资产概览、目标入口、退出登录

## 目录结构

```
wealth-manor/
├── README.md               # 本文档
├── package.json            # 根级便捷脚本（setup/dev/lint/format）
├── docs/
│   ├── ARCHITECTURE.md     # 架构与扩展点（含 Mock→真实服务替换指南）
│   ├── API_SPEC.md         # 接口规范（变更流程：先改文档再实现）
│   └── DEV_PROCESS.md      # 开发规范（分支/提交/命名/协作）
├── scripts/
│   └── capture-demo.mjs    # 无头浏览器截图（生成企划书配图）
├── server/                 # Express 后端
│   └── src/
│       ├── routes/         # 路由层：/api/v1 各领域路由
│       ├── services/       # 业务逻辑层（含纯函数，可单测）
│       ├── providers/      # 数据提供方注册表（扩展点）
│       ├── middleware/     # 日志/鉴权/错误处理
│       ├── data/           # 数据驱动配置（植物/任务/题库/资产）
│       └── utils/          # 统一响应/确定性随机
└── web/                    # Vue3 前端
    └── src/
        ├── api/            # 接口封装（与后端路由一一对应）
        ├── components/     # 通用组件（手机框/Tab/庄园场景/图表）
        ├── views/          # 四大模块页面
        ├── stores/         # Pinia 状态
        ├── composables/    # 组合式函数（ECharts 挂载）
        └── utils/          # 格式化/Toast
```
